## 💻 MacBook (macOS)
- **Онлайн**: открой ссылку в **Safari** или **Chrome**. В Safari можно нажать **«Файл» → «Добавить в Dock»** для запуска в отдельном окне.
- **Локально (без интернета / для теста правок)**: запусти двойным кликом файл **`Запустить_на_Mac.command`** из папки игры (при первом запуске: правый клик → **«Открыть»**) или выполни в Терминале внутри папки:
  ```bash
  python3 -m http.server 8090 --bind 0.0.0.0
  ```
  После этого открой **`http://localhost:8090/`** на MacBook (или `http://<IP-Мака>:8090/` на iPhone в той же Wi‑Fi сети).

## 📱 iPhone / iPad (iOS) и Android — без верхней панели браузера

- **На iPhone (Safari)**: открой ссылку именно в **Safari** (не внутри приложения GitHub или Telegram) → нажми кнопку **«Поделиться»** → выбери **«На экран „Домой“»**. Игра появится как отдельная иконка и будет запускаться на 100% экрана без рамок и ссылок (либо в самом Safari нажми значок меню у адресной строки → **«Скрыть панель инструментов»**).
- **На Android (Chrome)**: игра автоматически разворачивается на весь экран при первом касании, либо открой меню браузера `⋮` → выбери **«Установить приложение» / «Добавить на главный экран»**.
