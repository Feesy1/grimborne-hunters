## 💻 Запуск на MacBook (macOS)

### Способ 1 — Онлайн в 1 клик (рекомендуется)
1. Откройте ссылку **`https://feesy1.github.io/grimborne-hunters/`** в **Safari** или **Chrome** на MacBook.
2. По желанию: в Safari нажмите **«Файл» → «Добавить в Dock…»** (macOS Sonoma и новее) — игра откроется как отдельное приложение.

### Способ 2 — Локально из скачанного репозитория (`Запустить_на_Mac.command`)
1. Склонируйте или скачайте репозиторий на MacBook:
   ```bash
   git clone https://github.com/Feesy1/grimborne-hunters.git
   cd grimborne-hunters
   ```
2. Запустите файл **`Запустить_на_Mac.command`** двойным кликом (или в Терминале: `chmod +x Запустить_на_Mac.command && ./Запустить_на_Mac.command`).
   > Если macOS предупредит о неизвестном разработчике — нажмите на файл правой кнопкой → **«Открыть»**.
3. Либо вручную в Терминале одной командой (нужен встроенный `python3`):
   ```bash
   python3 -m http.server 8090 --bind 0.0.0.0
   ```
   И откройте в браузере **`http://localhost:8090/`**.
   В терминале также выведется локальный Wi‑Fi адрес вида **`http://192.168.x.x:8090/`** — по нему можно сразу играть с iPhone в той же Wi‑Fi сети.

## 📱 Запуск на iPhone / iPad (iOS) и Android

- **На iPhone (Safari)**: откройте `https://feesy1.github.io/grimborne-hunters/` именно в **Safari** (не внутри встроенного браузера Telegram/GitHub) → **«Поделиться»** → **«На экран „Домой“»**. Игра будет открываться во весь экран как отдельное приложение без адресной строки.
- **Локально с MacBook на iPhone**: запустите `Запустить_на_Mac.command` на Mac и откройте на iPhone в Safari показанный адрес `http://<IP-Мака>:8090/`.
- **На Android (Chrome)**: меню `⋮` → **«Установить приложение» / «Добавить на главный экран»**.
