## 📱 Запуск на iPhone / iPad (iOS) и Android
- **Быстрый старт на телефоне**: игра теперь загружает на старте только выбранного героя, оружие и врагов текущей главы — загрузка на iPhone стала кратно быстрее без зависания заставки; остальные модели подгружаются фоном.
- **Сброс старой версии на iPhone (Safari / экран «Домой»)**:
  1. Откройте в **Safari** именно обновлённую ссылку `https://feesy1.github.io/grimborne-hunters/?v=20261117z20`.
  2. Нажмите **«Поделиться»** → **«На экран „Домой“»**, чтобы иконка на рабочем столе запускала игру во весь экран без рамок браузера. *(Если старая иконка с рабочего стола всё ещё открывает прошлую версию — удалите старую иконку и добавьте новую по ссылке `?v=20261117z20`.)*
- **На Android (Chrome)**: меню браузера `⋮` → **«Установить приложение» / «Добавить на главный экран»**.

## 💻 Запуск на MacBook (macOS)

### Способ 1 — Онлайн в 1 клик (рекомендуется)
1. Откройте **`https://feesy1.github.io/grimborne-hunters/?v=20261117z20`** в **Safari** или **Chrome** на MacBook.
2. По желанию в Safari нажмите **«Файл» → «Добавить в Dock…»** — игра откроется как отдельное приложение.

### Способ 2 — Локально из репозитория (`Запустить_на_Mac.command`)
1. Склонируйте или обновите репозиторий на MacBook:
   ```bash
   git clone https://github.com/Feesy1/grimborne-hunters.git
   cd grimborne-hunters
   ```
2. Запустите файл **`Запустить_на_Mac.command`** двойным кликом (или в Терминале: `chmod +x Запустить_на_Mac.command && ./Запустить_на_Mac.command`).
   > Если macOS предупредит о неизвестном разработчике — правый клик по файлу → **«Открыть»**.
3. Либо вручную в Терминале:
   ```bash
   python3 -m http.server 8090 --bind 0.0.0.0
   ```
   Откройте на Mac **`http://localhost:8090/`**, а в Терминале также выведется локальный адрес вида **`http://192.168.x.x:8090/`**, по которому игру можно открыть с iPhone по домашнему Wi‑Fi.
