# Шаблон чёткого задания для AI-разработки (`TASK_BRIEF_TEMPLATE`)

> Используй этот короткий шаблон перед любой крупной задачей (новый сектор, враг, оружие, рефакторинг), чтобы ИИ не додумывал архитектуру и стиль.

```markdown
## Задача: <Короткое название>
- **Приоритет:** P0 / P1 / P2 / P3
- **Цель:** Что именно должно появиться или измениться для игрока.
- **Контекст и файлы:** Какие документы/модули взять за основу (например: `docs/VISUAL_STYLE_GUIDE.md`, `js/souls/soulsSector01Slice.js`).
- **Референсы:** Ссылки на скриншоты, карту атласа или готовые ассеты.
- **Ограничения:**
  - Не раздувать монолиты (`combat.js`, `world.js`, `models.js`) — писать в отдельном модуле.
  - Масштаб строго от героя `1.60 м`, материалы матовые (`roughness 0.80–0.97`).
  - Коллизии строго 1:1 с мешами (SSOT).
- **Системы, которые НЕЛЬЗЯ сломать:** (сверить с `docs/SYSTEM_REGISTRY.md`, например: Замок Пепла, Кат-сцена побега, Сектор 01).
- **Ожидаемый результат:** Конкретный список файлов/поведений.
- **Критерии завершения (Стоп-критерий):**
  1. `tools/check_assets.py` — 0 ошибок.
  2. `tools/qa_smoke.py` — 0 ошибок консоли/HTTP, FPS >= 60, все ассерты пройдены.
  3. Живые скриншоты проверены глазами, прикреплена актуальная ссылка на GitHub Pages.
```
