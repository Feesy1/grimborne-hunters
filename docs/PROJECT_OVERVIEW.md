# Grimborne Hunters — Обзор проекта (`PROJECT_OVERVIEW`)

## 1. Что это за игра
**«Охотники Мрака» (*Grimborne Hunters*)** — мрачная 3D Dark-Fantasy Action RPG в духе *Dark Souls*, *Bloodborne* и *Elden Ring*, работающая прямо в браузере (ПК и мобильные устройства) при `60–150 FPS`.

- **Главный герой:** Воин Клятвы (`1.60 м` роста) — латник со щитом, перекатами, блоком/парированием, тяжёлыми атаками и сменным оружием ближнего боя (Меч Клятвы, Большая Дубина, Копьё, Цвайхандер, Секира, Молот).
- **Игровой путь:**
  1. **Пролог — Замок Пепла** (`castle`): костёр, коридор с ловушками и стражами, монументальные врата, схватка с Боссом **«Судья Руин»**.
  2. **Побег из Замка** (`chasm_only` → `shaft_river`): 5-актовая кинематографическая кат-сцена с обрушением пола, падением в подземную реку и прорывом решётки водоотвода.
  3. **Регион I — «Речной Предел»** (`exterior_shore`): взаимосвязанная открытая локация из 8 секторов (от выхода из водоотвода вдоль реки через рыбацкий посёлок и древние руины к заброшенному монастырю).

## 2. Технологии и ограничения
- **Движок:** Three.js `r160`, чистый ES6 JavaScript (`type="module"`), без сборщиков (`webpack`/`vite`).
- **Ассеты:** GLB 2.0 со сжатием Draco (создаются в **Blender 4.5.9 LTS**), процедурные + тайловые PBR-текстуры (`assets/env/textures/`), Web Audio API + сэмплы `.wav`/`.mp3`.
- **Деплой:**
  - **Основной живой стенд:** GitHub Pages — https://feesy1.github.io/grimborne-hunters/ (ветка `main` репозитория `https://github.com/Feesy1/grimborne-hunters.git`).
  - **Яндекс Игры:** обёртка `js/yandexSdk.js` с автоматическим локальным fallback (без внешних CDN!).
  - **Android:** обвязка Capacitor в `package.json` (`npm run build:www`).
- **Кэширование Safari/Mobile:** все модули и ассеты используют query-суффикс `?v=YYYYMMDDzNNN`, синхронно обновляемый через `tools/release.py`.

## 3. Текущий статус и главная цель этапа
- **Актуальная сборка:** `z106` (база игры `z105` + внедрённая система AI-разработки).
- **Фокус прямо сейчас:** приёмка эталонного **Сектора 01 («01 • Выход из водоотвода»)** — проверка ощущения движения, масштаба, матовых материалов, 1:1 коллизий, живого мелководья и раздельных звуков.
- **Следующий шаг после приёмки Сектора 01:** поэтапное перенесение того же стандарта качества на **Сектор 02 («Речной тракт»)** и далее по атласу Речного Предела, добавление врагов и боевого контента открытого мира.
