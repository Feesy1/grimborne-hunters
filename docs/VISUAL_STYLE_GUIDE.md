# Grimborne Hunters — Визуальный стандарт (`VISUAL_STYLE_GUIDE`)

> Единый закон визуала игры. Любая новая 3D-модель, текстура, шейдер и локация обязаны соответствовать этому документу. Эталон качества — сборка **`z105` (Сектор 01)**.

## 1. Художественное направление
- **Стилизация:** полуреалистичное мрачное тёмное фэнтези с выразительным силуэтом и читаемыми формами (в духе *Dark Souls III* / *Bloodborne* / *Elden Ring*, адаптированное под стилизованного компактного героя-рыцаря).
- **Референсы персонажа:** лежат локально в `D:\GrimborneHunters\Референсы_для_3D\` (не в Git).
- **Главный запрет:** никогда не смешивать стили в одной зоне (запрещены одновременно мультяшный пластик, «воксельные» коробки, неоново-синие руны и 3 разных дизайна фонарей на одной улице).

## 2. Абсолютная метрика масштаба (якорь — герой `1.60 м`)
Все 3D-модели в Blender строятся **в реальных метрах** с обязательной проверкой рядом с манекеном героя **`1.60 м`**:

| Объект | Эталонный размер (метры) | Примечание |
| :--- | :--- | :--- |
| **Герой (Воин Клятвы)** | Высота **`1.60 м`**, радиус коллизии **`0.50 м`** | Базовый метр всего мира |
| **Бочка / Ящик** | Бочка `0.95 × 0.72 м` · Ящик `0.88 × 0.88 × 0.88 м` | По пояс/грудь герою |
| **Костёр и витой меч** | Каменное кольцо `Ø 2.10 м` · Меч **`1.12 м`** | НЕ гигантская «шпала» 2.3 м! |
| **Уличный фонарь** | Высота **`3.35 м`** (в 2.1× выше героя), единый готический дизайн | Матовое стекло внутри кованой клетки — НЕ жёлтый куб |
| **Жаровня у ворот** | Постамент `1.26 м` + чаша до `2.20 м` | Стоит с чистым зазором (`>= 0.8 м`) от стен |
| **Рыбацкая лодка** | Длина **`3.90 м`** × ширина `1.46 м` × борт `0.66 м` | Почти в 2.5× длиннее героя, с банками и вёслами |
| **Проход под аркой / воротами** | Ширина `5.0–6.6 м` × высота `6.0–8.6 м` | Свободный проход и комфортная работа 3rd-person камеры |
| **Дом / Хижина (будущие сектора)** | Высота стен `3.2–4.0 м`, конёк крыши `5.5–7.0 м`, дверной проём `>= 2.2 м` | Никаких «будок» по плечо герою |
| **Северная сосна** | Высота **`9.5–12.0 м`**, многоярусные свисающие лапы | Запрещены шипастые зелёные конусы |

## 3. Материалы и PBR (закон матовости)
> **Причина правила:** в `z101–z104` низкий `roughness` (`0.20`) и зеркальные лужи превращали землю в «глянцевую фотобумагу».

| Материал | `roughness` | `metalness` | `envMapIntensity` | Обязательные карты |
| :--- | :---: | :---: | :---: | :--- |
| **Камень / Брусчатка / Скалы** | `0.85–0.96` | `0.00` | `0.24–0.36` | Albedo + Normal + ORM + Vertex AO (`COLOR_0`) |
| **Влажный берег у воды** | `0.60–0.78` | `0.00` | `0.26–0.34` | Только мягкое потемнение, **БЕЗ зеркального блеска** |
| **Старое дерево (лодка, бочки, дома)** | `0.86–0.94` | `0.00` | `0.28–0.36` | Albedo + Normal + Vertex AO |
| **Хвоя и папоротники** | `0.92–0.96` | `0.00` | `0.22–0.28` | Vertex Colors / Alpha-cutout (`alphaTest: 0.42`) |
| **Кованое железо** | `0.50–0.62` | `0.68–0.78` | `0.40–0.50` | Vertex AO |
| **Матовое стекло фонаря** | `0.42` | `0.00` | — | Тёплое `emissive: 0xff9b38`, `emissiveIntensity: 1.55` |

## 4. Цветовая палитра и ночное освещение («Речной Предел»)
- **Небо и лунный свет (холодная база):** глубокий ночной сине-сланцевый (`#132032` – `#2c3e5e`), лунный `dirLight` (`intensity: 1.56`), холодный отражённый свет неба `hemiLight` (`#88a8dc` / `#36445c`, `intensity: 1.78`) + `ambientLight` (`#4b6288`, `intensity: 0.68`) — **тени читаемые, никогда не проваливаются в глухой чёрный**.
- **Очаги и фонари (тёплый акцент):** живой янтарно-огненный (`#ff8424` – `#ffaa4e`) строго от **стационарных `PointLight`**.
- **ToneMapping:** `ACESFilmicToneMapping`, `toneMappingExposure = 1.22` (внешний мир).
- **Запрещено:**
  - «Нарисованные» оранжевые круги краски на земле под кострами и фонарями;
  - Один телепортирующийся `PointLight`, который резко вспыхивает на герое;
  - Плоская ярко-зелёная заливка мхом (мох только приглушённый оливково-серый в стыках камней);
  - Водопады в виде сплошного белого «облака пара» (только полупрозрачные струи воды с белыми нитями пены).
